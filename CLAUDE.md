# CLAUDE.md

## Read HOUSE_RULES.md first — mandatory

Before the first substantive action of **any** session in this repo, read
`HOUSE_RULES.md` at the repository root and follow it for the whole session.
Do this before searching, reading source, planning, or editing.

From a worktree under `.claude/worktrees/`, the file is in the **base
checkout**, not in the worktree copy — read it from there.

`HOUSE_RULES.md` is gitignored and personal to each checkout, so it is not part
of a clone. If it is absent, say so once and continue with normal defaults;
do not invent its contents.

Where it conflicts with a default behaviour, `HOUSE_RULES.md` wins. It is the
authority on commit and branch policy, what "done" requires before a change may
be called finished, comment style, and the environment and engine invariants
that are easy to break without noticing.
