# v1.1.0 release guide

The [v1.1.0 tag](https://github.com/fcmv/Vector-64/tree/v1.1.0) identifies the
source for this release. Downloads and their checksums belong on the
[release page](https://github.com/fcmv/Vector-64/releases/tag/v1.1.0).
See the [changelog](../changelog.md) for the full changes since v1.0.0.

## Choose a binary

Platform profiles cover Linux x86-64-v2/v3, Linux ARM64/ARM64-dotprod, macOS
ARM64 and Windows AVX2. Windows needs AVX2; Linux v3 needs the full x86-64-v3
baseline, including BMI2. Linux assets build on Ubuntu 24.04. CPU support does
not establish OS/runtime compatibility; consult the platform build record.

Suffixes select classical search (none), embedded standard NNUE (`-nnue`),
standard NNUE plus classical drop variants (`-all`), classical drop variants
without embedded weights (`-variants`), JSON rule queries (`-validator`), and
Vector Scope (`-viz`). Windows filenames end with `.exe` after the suffix.

Download `release-notices.zip` with an executable. `release-source.tar.gz`
contains the corresponding source. `SHA256SUMS`, per-platform `.build.json`
records and `release-builds.json` identify the final files, toolchains, network
and UI. These are checksums and build records, not signatures or attestations.

## Search and visualize

A UCI GUI handles the protocol. For a manual NNUE search, send `uci`, wait for
`uciok`, send `isready`, wait for `readyok`, then enter:

```text
setoption name Threads value 1
setoption name Hash value 64
ucinewgame
position startpos moves e2e4 e7e5
go depth 6
```

Wait for `bestmove` before `quit`. Launch the `-viz` binary with `--headless`
to serve the embedded Vector Scope UI at `http://127.0.0.1:7777`.
The visualizer is a local, unauthenticated tool; see the
[visualizer guide](../visualizer.md).

The shipped [STK-HalfKA network](../vector64-spec.md) and weights are unchanged
from the v1.0.0 architecture baseline: 22,528 features per perspective,
H=1024 accumulators, paired clipped activation, and eight output buckets with
1024 -> 16 -> 32 -> 1 dense layers and a PSQT side output. H=128 remains an
optional runtime width; no small-network weights are shipped.

## Robustness changes and boundaries

Drop variants consistently use classical evaluation, including helper threads.
Threaded TT probes take coherent snapshots. Big-network accumulator work can
be deferred when a small-network/lazy gate skips evaluation. Search and UI
depth limits share the same bound; browser stacks are explicitly sized and
checked. Datagen recovery validates the destination and transport reply;
recording appends preserve earlier bytes. RL training-input preparation uses
deterministic generation-local inputs and integrity manifests.

The source also includes `--perft-divide`, shared training tools and guarded
benchmark collection added since v1.0.0. Read the tagged source documentation
when using those Python tools.

These changes do not repair the material-adjudication, nontransactional
network-replacement or Syzygy boundaries in [known limitations](../limitations.md).
Browser dataset recovery uses the existing virtual filesystem; it does not
promise persistence across page reloads. No absolute Elo rating or general
performance improvement is established by this release.
