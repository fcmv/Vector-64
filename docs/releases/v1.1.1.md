# v1.1.1 release guide

The [v1.1.1 tag](https://github.com/fcmv/Vector-64/tree/v1.1.1) identifies this
release. Downloads, checksums and build records are on the
[release page](https://github.com/fcmv/Vector-64/releases/tag/v1.1.1).
See the [changelog](../changelog.md) for changes since v1.1.0.

## Syzygy corrections

Root DTZ ranking now preserves UCI `searchmoves`. If the caller excludes all
globally optimal moves, the engine ranks the allowed legal moves instead of
replacing them. WDL fallback preserves the same restriction. Missing coverage
continues with normal search.

DTZ receives whether any position repeated since the last capture or pawn
move, including earlier cycles when the current root has not repeated. Supply
game moves in the UCI position command to preserve that history; a FEN alone
cannot reconstruct it. The adapter regression runs without external data;
`STK_SYZYGY_TEST_PATH` enables additional tests against real three-piece WDL
and DTZ files. Tablebase files are not included in the release.

Draft publication now finds authenticated drafts omitted by GitHub's release
tag endpoint. Uploads still require the exact source commit, complete local
checksums and matching server-reported digests before publication.

## Downloads and compatibility

Platform profiles and executable capabilities are unchanged from
[v1.1.0](v1.1.0.md#choose-a-binary): Linux x86-64-v2/v3, Linux ARM64 and
ARM64-dotprod, macOS ARM64 and Windows AVX2. Each platform ships classical,
embedded-NNUE, combined variants, variant-only, validator and Vector Scope
executables. Windows filenames end with `.exe` after the capability suffix.

Download `release-notices.zip` alongside an executable. Verify files against
`SHA256SUMS`; consult the per-platform `.build.json` files and
`release-builds.json` for exact compiler, CPU, source, network and UI identities.
`release-source.tar.gz` contains corresponding tracked source. These records
are checksums and build information, not signatures or attestations.

Windows requires AVX2; Linux x86-64-v3 also requires BMI2. The dot-product
ARM64 build requires ARMv8.2 dot-product support. Linux builds use Ubuntu 24.04;
CPU support does not establish OS/runtime compatibility.

The NNUE weights, STK-HalfKA topology and standard search fingerprints with
tablebases disabled remain unchanged. See the [network contract](../vector64-spec.md).
The README's video preview now opens the final platform-card edit.

## Remaining limits

The material-adjudication defect and nontransactional network-replacement
failure remain documented in [known limitations](../limitations.md). DTZ needs
matching external table files; WDL fallback alone lacks DTZ progress guidance.
This release establishes no absolute Elo rating or general speedup.
